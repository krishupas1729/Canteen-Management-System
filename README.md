
# Canteen Management System

## Project Overview
The Canteen Management System is a Python and MySQL based application designed to manage daily canteen operations efficiently.

## Technologies Used
- Python
- MySQL
- XAMPP
- PyCharm

## Features
- User Login System
- Dashboard
- Product Management
- Category Management
- Order Management
- Payment History
- Purchase Management
- Inventory Management
- Expense Management
- Reports

## Database
The application uses MySQL as its database to store and manage canteen records.

## Project Modules
- main.py - Main application
- login.py - User authentication
- dashboard.py - Dashboard
- products.py - Product management
- categories.py - Category management
- orders.py - Order management
- purchases.py - Purchase management
- operations.py - Canteen operations
- reports.py - Reports
- db.py - Database connectivity

## Installation and Setup
1. Install Python.
2. Install XAMPP and start MySQL.
3. Create the required MySQL database.
4. Import the provided SQL database file using phpMyAdmin.
5. Install the required Python packages.
6. Configure database connectivity in db.py.
7. Run main.py.
